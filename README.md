# asadprodhan.github.io

Personal academic website for Dr Asad Prodhan.

## Deploy

Copy the contents of this folder into the root of the `asadprodhan.github.io` GitHub repository and push to the default branch used by GitHub Pages.

## Important

The navigation link to `bcrti/` assumes the existing BCRTI site remains available at `https://asadprodhan.github.io/bcrti/`. Do not delete the existing `bcrti` directory when replacing the root homepage unless BCRTI is hosted elsewhere.
